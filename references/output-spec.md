# 产物规格：邮件正文 + Word 深度版

来源：`handbook.md` 第 5 节与 `report-template.md`。两者冲突时以手册/模板为准；这里只是速查。

## 一、邮件正文（精简版）

纯文本、无 Markdown 符号，整篇 1500–2500 字，每条要点 **200–300 字**：

1. `📅 半导体晨报 · YYYY-MM-DD`（休市时标注）
2. **一句话总览**：今天最该知道的产品级变化
3. **3–5 条产品要点**，每条固定六要素：
   `型号/节点 → 关键参数 → 进度 → 卡点 → 供应链影响 → A 股落点（标的 + 时效）`
4. **主流看法**：分「共识 / 分歧 / 新变量」三段，每段 150–250 字，点名机构与判断
5. **映射表**（4–7 行）：环节｜方向｜标的｜产品逻辑｜时效
6. **本周产品事件**（GTC / 财报 / 出口数据 / 展会）
7. **说明**：附件为 Word 深度版 + 非投资建议声明

## 二、Word 深度版（八章骨架）

1. 今日产品要点（3–5 条，每条 200–300 字段落，六要素齐全）
2. 产品与工艺进展：2.1 先进制程与封装 / 2.2 存储与价格 / 2.3 算力芯片与终端 / 2.4 设备与材料（表格）
3. 主流看法（共识 / 分歧 / 新变量 + 来源表 + 一句话结论：已 price in 什么、还差什么）
4. 对 A 股 / 港股的影响映射（环节｜方向｜代表标的｜产品逻辑｜时效）
5. 产品事件日历（时间｜事件｜产品口径关注点）
6. 风险提示与判断失效信号（产品端证伪 / 估值端 / 触发条件）
7. 来源清单（媒体｜标题｜发布时间｜链接，**12 条**）
8. 生成元信息（检索关键词、检索异常、条目统计：产品/看法/事实/预期/传闻）

结尾固定声明：

```
> 本报告由公开信息自动整理，不构成投资建议。产品参数与价格请以厂商公告为准。
```

## 三、质量红线（交付前逐条打勾）

- [ ] 每条产品信息到“型号/节点/规格”层面，不出现空泛描述
- [ ] 每条事实有来源链接 + 发布时间
- [ ] 事实 / 机构预期 / 未证实传闻三者区分清楚（传闻标“未经证实”）
- [ ] 没有编造数字、价格、客户、证券代码；不确定处写“待确认”
- [ ] A 股映射带证券代码（代码以行情软件为准），并标注传导时效
- [ ] 主流看法至少 3 家机构 + 1 个产业界口径，标注共识/分歧/新变量
- [ ] 休市日已标注
- [ ] 邮件主题没有重复添加插件前缀（如 `[DSH]`）
- [ ] 发送成功后本地 md/docx 已删除
